## Como usar

1. Copie o repositorio para a sua máquia usando

```bash
git clone <link_repositorio>
```

2. Entre na pasta do repositorio e digite em seu terminal

```bash
npm install
```

3. Após instalar as dependências, rode localmente utilizando

```bash
npm run dev
```
